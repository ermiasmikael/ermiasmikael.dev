A production-ready, multi-tenant trade sanctions screening platform combining enterprise Java microservices with an agentic AI tier.

`Java 21 / Spring Boot` → `Kafka / Redpanda` → `PostgreSQL / OpenSearch` → `Python / FastAPI` → `MCP + RAG + Tool Calling`
